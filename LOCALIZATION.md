# Локализация ru / en / tr

## Использование

В главном меню: **Настройки → Язык → Русский / English / Türkçe**.
Язык меняется сразу и сохраняется в `PlayerPrefs` под ключом `Localization.Language`.
При запуске приоритет имеет сохранённый выбор, затем язык Яндекс SDK, затем английский.
Коды вроде `ru-RU` и `tr_TR` нормализуются. Поздний ответ SDK не меняет ручной выбор.

Словари: `Assets/MedivalTycoon/Resources/Localization/{ru,en,tr}.asset`.
В каждом — одинаковые 64 ключа, включая 22 шага обучения.
Если отдельный перевод отсутствует, используется английский текст.

## Добавление текста

1. Добавить одинаковый ID во все три `LocalizationData` через Unity Inspector.
2. Для статической надписи добавить `LocalizedText` на объект с `TMP_Text` или `UI.Text` и заполнить Key.
3. Для текста с параметрами вызвать, например:

```csharp
Localization.LocalizedText.Bind(label, "victory.reward", earnedCoins);
```

Компонент сохраняет параметры, обновляет текст при смене языка и при повторном открытии.
Для составного UI можно подписаться на `LocalizationManager.LanguageChanged` и заново получить строки
через `Get` / `Format`; при отключении нужна отписка. Так обновляется панель улучшений.
Числовые параметры форматируются одинаково во всех языках (`InvariantCulture`).
В обучении поле `MessageKey` хранит ключ; текст меняется без повторного запуска логики шага.

## Проверки

- `Tools → Localization → Validate translations`: пустые значения, дубликаты, отсутствующие ключи,
  параметры и синтаксис формата, ссылки в коде и сценах. Ошибки блокируют сборку.
- `Tools → Localization → Run behavior checks` в Play mode: выбор/сохранение языка,
  приоритет над SDK, обновление активных и скрытых надписей, английский резервный перевод.
- `python Tests/Localization/validate_localization.py`: проверка всех игровых сцен и префабов,
  подключённых компонентов, переводов и шагов обучения. Внешние Python-пакеты не нужны.

В рамках реализации прошли компиляция игровых и редакторских C#-скриптов, проверка файлов
и поведенческие проверки в изолированном Unity 2022.3.62f3 проекте.
Полная WebGL-сборка не выполнялась. По запросу пользователя шрифты, покрытие символов,
размеры окон и переносы не изменялись и визуально не проверялись.
